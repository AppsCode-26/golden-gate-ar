# Golden Gate AR Card

A fold-out card with a QR code. Scanning it opens a web page that shows a 3D Golden Gate Bridge (with the Marin Headlands) standing on top of the picture inside the card.

- **Live page:** https://appscode-26.github.io/golden-gate-ar/
- **Print:** `card.pdf` (page 1 = outside, page 2 = inside; print double-sided on letter paper, flip on short edge, fold in half)
- **Pinch** with two fingers to resize; move the phone around to look at it from any side.
- No card handy? Tap "No card? View in 3D" on the page.

Built with [MindAR](https://github.com/hiukim/mind-ar-js) image tracking + three.js.

3D model: "Golden Gate Bridge 3D Model" (https://sketchfab.com/3d-models/golden-gate-bridge-3d-model-0f1bf2d780ad4cb6b4e0f4c650f6cdfc) by damongraphics (https://sketchfab.com/damongraphics), licensed under CC BY 4.0 (http://creativecommons.org/licenses/by/4.0/). Recolored, cropped and simplified for phones.
